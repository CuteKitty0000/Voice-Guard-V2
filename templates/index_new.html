VoiceGuard API Reference

Integration-ready REST and WebSocket APIs for enterprise voice integrity verification

REST Endpoints

Standard HTTP for batch audio file analysis

POST/predict
Analyze audio files. Returns AI risk score and verdict for each file.
curl -X POST http://localhost:5000/predict -F "audio=@call.flac"
# Response: {"results":[{"ai_pct":98.2,"verdict":"AI","risk_level":"HIGH"}]}

WebSocket Events

Real-time bidirectional communication for live call monitoring

EMITaudio_chunk
Send a 3s audio buffer for real-time analysis. Responds with risk_update.
const socket = io();
socket.emit("audio_chunk", audioArrayBuffer);
socket.on("risk_update", d => console.log(d.risk_level, d.ai_pct+"%"));
EMITenroll_voiceprint
Enroll trusted voiceprint for cross-session identity verification.
socket.emit("enroll_voiceprint", audioArrayBuffer);
socket.on("enrollment_done", d => console.log(d.status));

Response Schema

{"ai_pct":number, "human_pct":number, "verdict":"Human|AI",
 "risk_level":"LOW|MEDIUM|HIGH", "identity_score":number,
 "low_confidence":boolean, "warnings":string[]}
